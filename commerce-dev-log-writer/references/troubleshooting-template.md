# Troubleshooting Template

트러블슈팅 문서는 "무슨 일이 있었고, 왜 그랬고, 어떻게 해결했고, 무엇을 배웠는가"가 남게 작성한다.

확인되지 않은 항목은 지어내지 말고 `(작성 필요)`로 남긴다.

## 작성 순서

1. 증상과 실제 에러 메시지를 먼저 적는다.
2. 재현 방법을 적는다.
3. 원인 분석은 확인된 근거와 추정을 구분한다.
4. 실패한 시도도 표에 남긴다.
5. 최종 해결 방법과 배운 점을 정리한다.

```markdown
# [트러블슈팅] {문제를 한 줄로}
