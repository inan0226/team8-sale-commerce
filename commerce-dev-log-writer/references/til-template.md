# TIL Template

TIL은 하루 동안 구현하거나 배운 내용을 짧지만 구체적으로 남긴다. 단순 작업 목록보다 "왜 이렇게 했는지"와 "다음에 어떻게 적용할지"를 함께 적는다.

## 템플릿

```markdown
# [TIL] {YYYY-MM-DD} {주제}

## 오늘 한 일

- {구현/수정한 기능 1}
- {구현/수정한 기능 2}
- {테스트/문서화한 내용}

## 배운 점

### 1. {배운 개념 또는 기술}

{무엇을 알게 되었는지 작성}

### 2. {프로젝트에서 적용한 방식}

{팀8 프로젝트 코드에서 어떻게 적용했는지 작성}

## 막혔던 부분

{문제 상황을 간단히 작성. 없으면 생략 가능}

## 해결 과정

{어떤 방식으로 해결했는지 작성}

## 코드/설계 포인트

- {예: Controller는 ApiResponse로 응답한다}
- {예: 삭제 상품은 findByIdAndIsDeletedFalse로 제외한다}
- {예: 주문 상품은 스냅샷으로 저장한다}

## 다음에 할 일

- {추가 구현}
- {테스트 보강}
- {리팩토링}

## 한 줄 회고

{오늘의 핵심 배움 또는 느낀 점 한 문장}
```
