# PR AI Usage Template

8 team 프로젝트 PR 템플릿의 AI 활용 내역을 작성할 때 사용한다. AI가 한 일과 작성자가 직접 이해/검증한 일을 분리해 과장 없이 작성한다.

## 작성 원칙

- 사용한 AI 도구를 사실대로 표시한다.
- 코드 이해 여부를 "이해 함"으로 체크하려면, 작성자가 직접 설명 가능한 범위만 적는다.
- AI가 생성한 내용을 그대로 붙였다고 쓰기보다, 어떤 범위에서 도움을 받았고 어떤 검증을 했는지 적는다.
- 빌드/테스트 통과 여부를 확인하지 않았으면 통과했다고 쓰지 않는다.

## PR 본문 템플릿

```markdown
## 🤖 AI 활용 내역

### 사용 여부
- [ ] 사용 안 함
- [x] ChatGPT 사용
- [ ] Codex 사용
- [ ] 기타 AI 도구 사용

### AI 코드 이해 여부
- [x] 이해 함

### 활용 범위
- [ ] 코드 작성
- [ ] 코드 리팩토링
- [ ] 코드 리뷰
- [ ] ERD 설계 검토
- [ ] API 명세 검토
- [ ] 예외 처리 검토
- [ ] 테스트 코드 작성
- [x] 문서 작성
- [ ] 기타

### 활용 내용

- {예: Cart/Order 도메인 구현 과정에서 발생한 문제 해결 과정을 트러블슈팅 문서 형식으로 정리하는 데 활용했습니다.}
- {예: 팀 코드 컨벤션과 실제 구현 방식이 맞는지 체크리스트를 만드는 데 활용했습니다.}
- {예: AI가 제안한 내용은 직접 코드와 테스트를 확인한 뒤 필요한 부분만 반영했습니다.}
```

## 리뷰어 공유 사항 템플릿

```markdown
## 🔗 공유 사항 to 리뷰어

- {예: CartItem soft delete와 unique 제약 조합에서 재추가 흐름이 의도대로 동작하는지 봐주세요.}
- {예: 주문 생성 시 재고 차감과 CartItem soft delete가 같은 트랜잭션에서 처리되는 흐름을 중점적으로 봐주세요.}
- {예: ErrorCode 선택이 팀 컨벤션과 맞는지 확인 부탁드립니다.}
```
